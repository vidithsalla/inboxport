# Security

InboxPort is an invite-only prototype and is not ready for unrestricted public
use. Do not connect a sensitive work mailbox without understanding the
limitations documented in [Security and privacy](docs/security-and-privacy.md)
and [Known limitations](docs/limitations.md).

Please do not open a public issue containing credentials, mailbox data, private
account identifiers, or exploit details. Use the contact method listed on the
repository owner's GitHub profile for private disclosure.
