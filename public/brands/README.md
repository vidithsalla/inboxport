# Integration brand assets

These files are stored locally so InboxPort does not rely on third-party image
hosting at runtime. They are used only to identify mail providers and AI
assistants that InboxPort connects.

- `gmail.svg`: Gmail icon introduced May 19, 2026. Google announced the
  Workspace icon refresh on May 26, 2026. The SVG was retrieved from Wikimedia
  Commons, where the source is attributed to Google.
- `outlook.svg`: Microsoft Outlook icon introduced October 1, 2025. The SVG was
  retrieved from Wikimedia Commons, where the source is attributed to
  Microsoft's Microsoft 365 site.
- `claude.svg`: The rounded Claude icon from Anthropic's January 2026 press kit.
- `chatgpt.svg`: OpenAI's current Blossom symbol, retrieved from Wikimedia
  Commons. The file is attributed to OpenAI and was pulled from the ChatGPT CDN
  in April 2026.

The logos are trademarks of their respective owners and should remain
unaltered.
